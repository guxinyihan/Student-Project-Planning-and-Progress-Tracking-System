# Backend 开发入口

此目录预留 Web 接口、用例协调和持久化适配代码，尚无服务或数据库配置。

按功能建立项目/成员/任务、依赖/计划、概览/风险三个接口区域；具体 URL、语言和框架待选型。业务规则调用[领域模块](../domain/README.md)，后端负责读写项目记录、保存有效变更、触发相关分析、提供页面一致的数据与可理解的错误。

首个用例：创建项目和成员、保存一个分配给同项目成员的正数工期任务，再重新读取核对字段。成员删除先检查其任务是否需重新分配。非法工期、跨项目分配或依赖拒绝时不写入候选变更。

随后接入有效图的校验与计划分析；任务、工期和依赖变更保存后自动刷新结果，状态及日期变更更新对应概览。持久化事务、错误结构、项目隔离及访问控制的具体策略需与团队确认。

计划数据保存与重新打开的一致性须通过集成场景验证。测试存储与开发存储分离；未来配置样例只能包含示例值。三人按[功能分工](../../docs/TEAM.md)协作，WeiMingrui 协调接口与集成。

参考：[架构](../../docs/ARCHITECTURE.md)、[需求](../../docs/REQUIREMENTS.md)、[测试](../../tests/README.md)。
