# 项目与任务管理（F1–F2）

功能负责人：**ZhangWeiyi**。来源：proposal 第 7、11、13 节。

职责：项目创建与编辑、起始日/截止日期、成员增删与重新分配检查、任务增删改、同项目负责人分配、正数自然日工期、任务截止日期和基础状态。

输入为现有项目记录和候选变更，输出为有效源数据或明确的校验错误。持久化由后端执行；依赖图合法性交给 scheduling，进度和风险由 monitoring 派生。基础状态仅有 `Not Started`、`In Progress`、`Completed`，不保存 `Blocked` 为第四种基础状态。

首个开发入口：建立项目、添加成员、创建并分配任务，拒绝无效工期与跨项目分配；经后端保存并重新打开核对。删除成员和任务涉及分配及依赖，必须先约定交互与处理策略，避免静默丢失关联数据。

验收与后续入口：[需求](../../../docs/REQUIREMENTS.md)、[路线](../../../docs/ROADMAP.md)、[测试](../../../tests/README.md)。
