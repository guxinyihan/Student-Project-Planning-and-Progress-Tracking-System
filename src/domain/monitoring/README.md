# 进度与计划风险监控（F5–F6）

功能负责人：**ZhangYuyang**。来源：proposal 第 9.5–9.6、11、13 节。

输入：有效项目快照、计划分析结果和显式的当前日期。输出：任务显示状态、未完成前置任务的名称、四类计数、完成率，以及带任务/截止日期和原因的风险说明。

未完成任务有未完成前置时显示 `Blocked`，同时保留其基础状态。前置完成后解除阻塞。每个任务只计入 `Completed`、`In Progress`、`Not Started`、`Blocked` 中的一类。完成率按已完成任务数/全部任务数计算；空项目显示 `No tasks yet`，不作零除。

风险分别说明未完成关键活动（包括被阻塞的关键任务）、未完成且逾期的工作，以及计算结束时间超过任务/项目截止日期的计划冲突。完成任务不产生“未完成工作逾期”提醒；状态更新不推断剩余工期或保证实际完工时间。日期边界和状态一致性处理在第一周约定。

首个入口：从 proposal 四任务例显示 D 被 B、C 阻塞；将 A、B 标记完成时完成率为 50%，D 只被 C 阻塞；C 完成后 D 解除阻塞。再验证 10 天计划对应 9 天项目窗口的 1 天冲突。
