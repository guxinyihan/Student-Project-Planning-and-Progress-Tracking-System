# Development roadmap

The next milestones build on the recovered R1 + G1-A baseline and the completed static integration review.

| Milestone | Planned outcome |
| --- | --- |
| Integration preparation | Define the remaining interface work and the tests that will verify each change. |
| G1-B and G2 | Plan and complete the next two implementation stages with separate acceptance criteria. |
| Module integration | Connect the independently developed modules and validate the combined task, dependency, progress, and schedule workflows. |
| System acceptance | Run end-to-end and regression tests and record the results against the system acceptance criteria. |
| Release review | Review the validated system and confirm distribution requirements before considering a release. |

Progress updates will report verified milestones as they occur. The [project status](../project-status/PROJECT_STATUS_2026-11-09.md) records the latest verified baseline and scoped test results.
