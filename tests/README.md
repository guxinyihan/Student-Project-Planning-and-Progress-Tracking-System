## 执行记录要求

每次正式验收记录 AC 编号、代码版本、输入、期望、实际结果、通过/失败、执行者、日期和证据。拒绝依赖编辑需同时检查错误解释与持久化计划没有变化。性能记录须包含任务/依赖数、测试机器、编辑场景和耗时，不用未经测量的“流畅”代替结果。

失败用例保持可追溯，修正后只补充复测结果，不擦去原失败。Week 7 计划做集成测试和用户评估；Week 8 复测缺陷并整理测试、评估及贡献证据。避免将目标写成已经达成的成果。
